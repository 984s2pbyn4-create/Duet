# ДУЭТ — ретро для двоих

Игры для двоих на iPad, а телефоны вместо геймпадов. Ничего устанавливать не нужно: всё работает в браузере.

## Возможности

- **Встроенная игра «Танчики»** — для 1–2 игроков, ROM не нужен.
- **Эмулятор ретро-приставок** (EmulatorJS): NES/Денди, SNES, Sega Mega Drive и Master System, Game Boy и Color, GBA, N64, PlayStation, PC Engine. Игры — ваши ROM-файлы, они хранятся только на iPad.
- **Телефон как геймпад:** отсканируйте QR-код на экране iPad. Связь сначала пробуется напрямую (WebRTC), а если не выходит — через резервный сервер (MQTT).
- **Bluetooth-геймпады** Xbox, PlayStation, MFi и клавиатура.
- Можно установить на экран «Домой» — приложение откроется на весь экран со своей иконкой.

## Как выложить на GitHub Pages (с iPad или iPhone)

1. Зайдите на github.com и войдите в аккаунт (или зарегистрируйтесь).
2. Нажмите **«+» → New repository**. Имя, например, `duet`. Тип: **Public**. Нажмите **Create repository**.
3. На странице репозитория нажмите **uploading an existing file** (или **Add file → Upload files**).
4. Распакуйте архив в приложении «Файлы» (нажмите на zip-файл) и выберите **все файлы** из папки: `index.html`, `manifest.webmanifest`, `icon.svg`, `icon-32.png`, `icon-180.png`, `icon-192.png`, `icon-512.png`, `README.md`. Нажмите **Commit changes**.
5. Откройте **Settings → Pages**. В разделе *Build and deployment* выберите **Source: Deploy from a branch**, **Branch: main**, папку **/ (root)** и нажмите **Save**.
6. Через 1–2 минуты сайт откроется по адресу `https://ВАШ_ЛОГИН.github.io/duet/`.
7. На iPad откройте этот адрес в Safari → «Поделиться» → **«На экран Домой»**.

Чтобы обновить приложение, загрузите новый `index.html` тем же способом (Add file → Upload files) — файл заменится.

## Управление

| | Телефон | Клавиатура | Геймпад |
|---|---|---|---|
| Движение | крестовина | игрок 1: стрелки, игрок 2: WASD | крестовина / левый стик |
| Огонь / A | большая кнопка | игрок 1: пробел, игрок 2: F | A / ✕ |
| Пауза / меню | МЕНЮ | Esc | Start / Options |

В эмуляторе раскладка кнопок на телефоне подстраивается под выбранную приставку.

## Технологии

PeerJS (WebRTC), MQTT.js (резервный канал через публичные брокеры EMQX / HiveMQ / Mosquitto), EmulatorJS (ядра libretro), QRCode.js. Встроенная игра написана на Canvas 2D и Web Audio.

Публичные MQTT-брокеры видят только нажатия кнопок, но не игры и не файлы.
